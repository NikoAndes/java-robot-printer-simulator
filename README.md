# Java Robot & Printer Simulator

A Java OOP simulation featuring a **robot** and **printer** system built with a Swing GUI and MVC architecture.

## Features

- Robot movement simulation with directional control
- Printer queue management and job simulation
- Swing-based graphical user interface
- MVC (Model-View-Controller) architecture
- Maven build system

## Technologies

| Technology | Usage |
|---|---|
| Java 17+ | Core language |
| Swing | GUI Framework |
| Maven | Build & dependency management |

## Project Structure

```
src/main/java/com/umng/laboratorio3/
├── gui/          # Swing views
├── models/       # Domain entities (Robot, Printer)
├── robot/        # Robot logic
├── impresora/    # Printer logic
└── utils/        # Utility classes
```

## How to Run

```bash
git clone https://github.com/NikoAndes/java-robot-printer-simulator.git
cd java-robot-printer-simulator
mvn compile exec:java
```
